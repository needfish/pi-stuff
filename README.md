# hn — a Hacker News theme for pi

Dark gray palette with HN orange (`okhsl(28 100% 50%)`) accent. Grayscale syntax highlighting.

[dark preview]: background `okhsl(60 2% 16%)` warm dark gray, text 88% lightness, orange borders, links, and keywords.

## Install

```bash
mkdir -p ~/.pi/agent/themes
curl -o ~/.pi/agent/themes/hn.json \
  https://raw.githubusercontent.com/needfish/pi-stuff/main/themes/hn.json
```

Then select `hn` via `/settings` in [pi](https://github.com/earendil-works/pi), or set `"theme": "hn"` in `~/.pi/agent/settings.json`.
